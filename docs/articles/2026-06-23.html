今天这条 GitHub Trending 很小众，但方向很清楚：视频剪辑正在从“人操作软件”，变成“人和 AI 代理共同操作时间线”。

主角是 Palmier Pro，一个面向 macOS 的开源视频编辑器。它的定位不是再做一个轻量版剪映，而是把 AI 直接接进视频编辑的核心工作区：时间线。



Palmier Pro 目前只支持 Apple Silicon 设备上的 macOS 26 Tahoe。官方说它是用 Swift 从零构建的原生 Mac 视频编辑器，参考目标是 Premiere Pro，但重点是把 AI 工作流融进剪辑过程。

它最值得关注的地方有两个。第一，内置生成式 AI。用户可以在时间线编辑器里调用 Seedance、Kling、Nano Banana Pro 等模型生成视频和图片。也就是说，生成内容不再是先去网页里做素材，再下载导入剪辑软件，而是直接发生在剪辑现场。

第二，它支持和 AI agent 协作。Palmier Pro 打开后，会通过 HTTP 暴露一个 MCP server，地址是 http://127.0.0.1:19789/mcp。你可以把 Claude Code、Codex、Cursor 这样的工具接进来，让 agent 和你一起操作同一个视频项目。



这件事的关键不是“AI 会剪视频了”这么简单，而是视频软件开始变成一个可被 agent 理解和调用的工作环境。过去我们给 AI 的任务通常是文字型的：写脚本、改标题、翻译字幕、生成分镜。现在更进一步：AI 可以进入时间线，参与素材生成、结构调整、剪辑指令执行。

从 AI习语 的角度看，这类工具提醒我们：未来的提示词，不只是写给聊天框看的，而是写给具体软件环境看的。一个好提示词要能说明目标、素材、约束、输出格式，还要能被 agent 转成软件里的动作。



给你一个可直接练习的“视频 agent 提示词模式”：

任务：请基于当前时间线，帮我把这条视频剪成 60 秒以内的英文学习短视频。

背景：目标观众是正在学习 AI 英文表达的中文读者，视频语气要清晰、实用、有节奏。

素材：保留开头 3 秒的引入画面，删除重复停顿和低信息密度片段，优先使用含有关键词解释、例句和总结的部分。

结构：前 5 秒提出问题，中间 40 秒解释 2 到 3 个核心表达，最后 10 秒给一个可模仿的英文句型。

约束：不要改变原意，不要制造不存在的信息；字幕使用简洁中英双语；每屏字幕不超过两行。

输出：先给我剪辑方案，再列出要删除、保留、补充字幕的时间点，最后等待我确认后再执行。

你会发现，这种提示词其实是一种“软件操作说明书”。它不是让 AI 随便发挥，而是把剪辑判断拆成可执行的条件：谁看、看什么、删什么、保留什么、怎么输出。

如果你暂时用不上 Palmier Pro，也可以把这个方法迁移到任何 AI 视频工具里：先让 AI 读懂项目目标，再让它给出时间线级别的修改建议，最后才允许它执行。不要一上来就说“帮我剪得好一点”，因为这句话没有可验证标准。



顺手做一个英文学习动作：记住两个表达。

第一个是 timeline editor，时间线编辑器。它指的是视频、音频、字幕等内容按时间排列和编辑的工作区。

第二个是 exposes an MCP server，暴露一个 MCP 服务器。这里的 expose 不是“曝光”，而是“对外提供接口”。在技术语境里，你可以理解为：这个应用打开了一个入口，允许其他工具连接并调用它。



Palmier Pro 的开源边界也值得注意：官方说明，视频编辑器本体、MCP server 和 agent chat 是开源的；生成式 AI 处理部分是闭源的。编辑器本身免费，不需要登录即可下载使用，也可以免费用 MCP server 做实验；生成式 AI 功能需要登录和订阅。

这不是一个所有人今天都能立刻用上的工具，因为它要求 macOS 26 和 Apple Silicon。但它释放的信号很明确：AI 工具的下一站，不只是生成内容，而是进入专业软件，和人一起完成复杂项目。
