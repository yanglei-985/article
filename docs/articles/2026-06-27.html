很多人谈隐私，第一反应是消息有没有加密。但在 AI 工具越来越多、输入内容越来越长的今天，更关键的问题可能是：系统是否一开始就减少了可被识别、可被关联、可被长期追踪的信息。

今天 GitHub Trending Daily 上的 SimpleX Chat 就提供了一个观察样本。它把自己的核心定位说得很直接：SimpleX 是第一个不使用任何 user identifiers 的消息网络，目标是做到 private by design，也就是从设计上默认保护隐私。

这不是普通的“加密聊天”卖点。很多通信产品即使采用端到端加密，仍然可能依赖手机号、用户名、账号 ID、联系人图谱或服务器侧连接记录。SimpleX 试图做的，是连“你是谁”这个固定标识都尽量不生成。



SimpleX Chat 的 README 强调了几个关键点：它保护的不只是消息内容，也包括 metadata，比如你和谁聊天、什么时候聊天；它使用 double ratchet end-to-end encryption，并叠加额外的加密层；它提供 Android、iOS、桌面端，也有 Linux、macOS、Windows 上的终端/CLI 版本。

更有意思的是它的连接方式。你要和朋友建立私密连接，需要分享一个链接，或者当面、视频通话时扫描对方手机上的 QR code。分享链接的渠道本身不一定要安全，只要你能确认链接是谁发来的，并且连接已经在 SimpleX 中建立。连接之后，还可以验证 connection security code。

从 AI习语的角度看，SimpleX 最值得学习的不是“你要不要马上换聊天软件”，而是它背后的产品判断：隐私不是最后补上的设置，而是从身份、连接、元数据、默认流程开始设计出来的。
